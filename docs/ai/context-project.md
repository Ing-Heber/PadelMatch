# Project Context

## What this app is
PadelMatch is an Expo app for organizing padel matches and related player workflows.

## Current baseline
- Starter Expo Router structure is in place.
- Main app routes are under `app/` and `app/(tabs)/`.
- Shared UI helpers are under `components/`.
- Theme/constants live in `constants/` and `hooks/`.

## Technical expectations
- TypeScript-first code.
- Keep navigation aligned with file-based routing.
- Reuse existing themed components when possible.
- Keep platform behavior consistent unless there is a platform-specific requirement.

## Non-goals (for now)
- Large architectural rewrites.
- New state management libraries without clear need.
- Premature optimization before real usage feedback.
