# AI Context Index

Use this folder as the starter context pack for AI-assisted development.

## Files
- `context-project.md`: product and technical baseline.
- `context-workflow.md`: delivery standards and review checklist.

## How to keep this useful
- Keep each file short and factual.
- Update context when project direction changes.
- Prefer adding a new focused file instead of turning one file into a long document.

## Suggested update moments
- New feature area added
- App architecture decision changed
- Workflow/conventions changed in `DEV.md`
